## 三步跑起来

### 第 1 步 · 环境自检

```bash
cd 04_脚本
python3 run_comfy_batch.py --ping
```
看到 `工作流所需节点: 全部存在 ✓` 和四个模型名都列出来，才继续。

### 第 2 步 · 上传资产

```bash
python3 run_comfy_batch.py --upload-assets
```

### 第 3 步 · 跑片段

```bash
python3 run_comfy_batch.py --run 8A        # 先跑一个验证
python3 run_comfy_batch.py --run-seg 1     # 跑整段
python3 run_comfy_batch.py --run-all       # 跑全集 26 个
```

详细参数、段缝接法、补帧、剪辑 → **看 `05_文档/ComfyUI操作手册.md`**

## 三条铁律

1. **首帧只能放单格**，不能放四格板整板（会被渲染成四个人）
2. **每段末 1 秒是定格**，剪辑必须裁掉（10 段不裁 = 10 秒死画面）
3. **换场段（4/6/7/9/10）不能用上一场末帧当首帧**，空间必须换新图

## 与原文档的差异说明

原始工作台 `index.html` 引用的是「第1集12镜 + 第2集6镜、5角色、4场景、3道具、30 张图」的另一套资产，
而本包是按漫剧老李 Skill 重新走完六道锁 + Asset-First 后产出的**独立版本**：

| 原工作台 | 本包 |

两套资产**不要混用**：脸、场景、服装都对不上，混用必然穿帮。
